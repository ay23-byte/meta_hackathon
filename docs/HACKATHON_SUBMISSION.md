# Hackathon submission checklist

LabLens combines deterministic scientific analysis with optional Meta Llama
3.2 1B through local Ollama. It also retains a separately selected Muse Spark
integration and an explicitly labelled deterministic mock; these are not the
same model or provider. Do not call mock output a live model response.

- [ ] Verify your local Ollama model and a successful structured report; schema
      failure must remain visible and numerical results must remain available.
- [ ] Rehearse `DEMO_GUIDE.md`, including offline fallback and export.
- [ ] Review event eligibility, allowed models, track, submission form, deadlines,
      video requirements and model-license attribution in the official portal.
      Llama use is not asserted to satisfy any specific event requirement.
- [ ] Prepare problem statement, repository link, setup steps and a demo video
      if the portal requires one. Do not include secrets or sensitive data.
- [ ] Verify actual model, provider, results, licensing and limitations in any
      submitted description. Do not invent citations or user-impact metrics.

The repository's older `HACKATHON_RULES.md` records a prior rules review, not
an unconditional current eligibility or compliance determination.
